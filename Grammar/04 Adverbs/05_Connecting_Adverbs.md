# 📌 Connecting Adverbs
**TOEIC Grammar | Unit 04 — Adverbs | Part 5 of 8**
*Level: B1–B2 | Focus: Logical Connectors Between Clauses*

---

## 🧭 Overview

> **Connecting adverbs** (also called adverbial connectors) link two independent clauses or sentences by showing a **logical relationship** between them.
> TOEIC tests both **correct meaning** and **correct punctuation** when connecting adverbs are used.

---

## 📋 Common Connecting Adverbs — Meanings & Usage

| Adverb | Relationship | Example |
|---|---|---|
| **however** | Contrast / but | *Suggestions are accepted; **however**, few are acted upon.* |
| **therefore** | Result / so | *The deadline passed; **therefore**, the project was cancelled.* |
| **furthermore** | Addition / moreover | *The report was late; **furthermore**, it was incomplete.* |
| **besides** | Additional point | *It is too late; **besides**, you are tired.* |
| **nonetheless / nevertheless** | Concession (still true despite...) | *It was risky; **nonetheless**, we proceeded.* |
| **hence** | Result / conclusion (formal) | *He was unprepared; **hence**, he failed the interview.* |
| **then** | Sequence / next | *Say sorry to her; **then**, you'll receive her smile again.* |
| **otherwise** | Alternative / if not | *All is up to date as of June 30; **otherwise** indicated.* |
| **moreover** | Strong addition | *Sales dropped; **moreover**, expenses increased.* |
| **instead** | Alternative replacement | *Don't call; **instead**, send an email.* |
| **or else** | Threat / condition | *Register by May 2, **or else** you'll be disqualified.* |

---

## 📍 Punctuation Rules — Critical!

### Rule 1 — Between two clauses: use a **semicolon (;)**

> `[Clause 1]` **;** `[Connecting Adverb]` **,** `[Clause 2]`

> ✅ *"It is too late; **besides**, you are tired."*
> ❌ *"It is too late **besides** you are tired."* (missing semicolon)

---

### Rule 2 — After a coordinating conjunction: **no connecting adverb needed**

> If `although`, `because`, `since`, `while`, `but`, etc. are already present → **don't add a connecting adverb** — it becomes redundant.

> ❌ *"**Although** we were tired, **nevertheless** we kept on walking."*
> ✅ *"**Although** we were tired, we kept on walking."*
> ✅ *"We were tired; **nevertheless**, we kept on walking."*

---

## ⚠️ Relationship Map — Choose the Right Connector

| You want to show... | Use... |
|---|---|
| Contrast (surprising result) | `however` / `nonetheless` / `nevertheless` |
| Result / conclusion | `therefore` / `hence` / `thus` |
| Addition | `furthermore` / `moreover` / `besides` / `also` |
| Alternative / condition | `otherwise` / `or else` / `instead` |
| Sequence | `then` / `thereafter` |

---

## 🎯 Common TOEIC Traps

- **Trap 1 — Missing semicolon:** Connecting adverb used between two clauses without `;` → grammar error
- **Trap 2 — Redundant connector:** Conjunction (`although`) + connecting adverb (`nevertheless`) in the same sentence → remove one
- **Trap 3 — `however` vs `therefore`:** Read for contrast (however) vs. result (therefore)
- **Trap 4 — `otherwise` placement:** "Unless indicated... **otherwise**" → `otherwise` signals an alternative condition placed at the end

---

## 🧠 Exam Thinking Strategy

> **Step 1:** Read both clauses carefully — what is the **logical relationship**?
> **Step 2:** Check for contrast → `however` · `nonetheless` · `nevertheless`
> **Step 3:** Check for result/consequence → `therefore` · `hence` · `thus`
> **Step 4:** Check for additional info → `furthermore` · `moreover` · `besides`
> **Step 5:** Check punctuation — if connecting two full clauses → verify `;` is present.
> **Step 6:** If a conjunction already exists → do **not** add a connecting adverb.

## 📝 Practice Questions

### Q1
> *"Employee suggestions are always accepted by management; _____, most suggestions are usually not acted upon until after the board meetings."*

- (A) therefore
- (B) otherwise
- (C) instead
- **(D) however ✅**

> 💡 Clause 1: suggestions are accepted. Clause 2: they're rarely acted on. → **Contrast** → `however`. Notice the semicolon (`;`) before the blank — correct usage confirmed.

---

### Q2
> *"Unless indicated, all the information in this set of records is up to date as of June 30 _____."*

- (A) therefore
- **(B) otherwise ✅**
- (C) also
- (D) else

> 💡 "Unless indicated **otherwise**" = fixed phrase meaning "unless told something different." This is a common TOEIC collocation. `otherwise` here modifies the condition set by `unless`.

---

### Q3
> *"Mr. Johnson expressed interest in a marketing job; _____, the previous positions on his resume were exclusively in accounting."*

- (A) moreover
- **(B) however ✅**
- (C) therefore
- (D) otherwise

> 💡 Clause 1: interested in marketing. Clause 2: experience is only in accounting. → **Contrast** → `however`. `moreover` would add a supporting point, not a contrasting one.

## 🗂️ Error Log / Memory Tips

| Mistake | Fix | Memory Trick |
|---|---|---|
| No semicolon before connector | Add `;` before the adverb | Two full clauses joined by connector = `;` required |
| `although` + `nevertheless` | Remove one | Conjunction + connecting adverb = redundant |
| `moreover` in contrast context | Use `however` | `moreover` = more of the same; `however` = opposite |
| `therefore` in contrast context | Use `however` | `therefore` = result; `however` = surprise/contrast |

> ✏️ **Quick Relationship Chart:**
> - Opposite ideas → **however / nonetheless**
> - Result/effect → **therefore / hence**
> - Add more → **furthermore / moreover**
> - Alternative → **otherwise / or else**
> - Sequence → **then / thereafter**
