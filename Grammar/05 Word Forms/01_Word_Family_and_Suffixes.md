# 📌 Word Forms — Suffixes & The Word Family System
**TOEIC Grammar | Unit 05 — Word Forms | Part 1 of 5**
*Level: B1–B2 | Focus: Recognizing Word Classes by Suffix*

---

## 🧭 Overview

> **Word form questions** are the most common question type in TOEIC Part 5.
> The four blanks in a word family — Noun, Verb, Adjective, Adverb — each have a **specific suffix pattern**.
> Master the suffixes → answer faster and more accurately.

---

## 📂 The Four Word Classes — At a Glance

| Class | Role in Sentence | Position Signal |
|---|---|---|
| **Noun (N)** | Subject, Object, Complement | After: `a/an/the`, adjective, preposition |
| **Verb (V)** | Action or state | After: subject; before: object |
| **Adjective (Adj)** | Describes a noun | Before: noun; after: `be` verb |
| **Adverb (Adv)** | Describes verb/adj/adverb | Before: adj/adv; around verb |

---

## 📋 Noun Suffixes — Common Patterns

| Suffix | Example Words |
|---|---|
| `-tion / -sion` | information, decision, production, inspection |
| `-ment` | management, improvement, department, adjustment |
| `-ance / -ence` | attendance, performance, difference, reference |
| `-ity / -ty` | productivity, quality, ability, responsibility |
| `-ness` | awareness, effectiveness, promptness, readiness |
| `-al` (sometimes noun) | approval, proposal, dismissal, renewal |
| `-er / -or` | manager, supervisor, operator, distributor |
| `-ist` | specialist, analyst, journalist |
| `-ant / -ent` | applicant, consultant, resident |
| `-ee` | employee, trainee, attendee |
| `-ship` | leadership, membership, ownership |
| `-ure` | procedure, disclosure, expenditure |
| `-age` | percentage, advantage, shortage |

---

## 📋 Verb Suffixes — Common Patterns

| Suffix | Example Words |
|---|---|
| `-ize / -ise` | organize, maximize, customize, prioritize |
| `-ate` | evaluate, communicate, operate, allocate |
| `-ify` | simplify, qualify, notify, identify |
| `-en` | strengthen, widen, shorten, broaden |
| (bare form) | produce, manage, reduce, improve |

## 📋 Adjective Suffixes — Common Patterns

| Suffix | Example Words |
|---|---|
| `-ive` | productive, effective, innovative, competitive |
| `-al` | financial, professional, additional, operational |
| `-ous` | advantageous, numerous, various, serious |
| `-ful` | successful, helpful, careful, meaningful |
| `-less` | careless, effortless, countless, seamless |
| `-able / -ible` | available, reliable, responsible, flexible |
| `-ent / -ant` | significant, consistent, efficient, relevant |
| `-ic` | economic, strategic, systematic, realistic |
| `-ary / -ory` | introductory, preliminary, mandatory, customary |
| `-ed` (participial) | experienced, motivated, dedicated, established |
| `-ing` (participial) | promising, challenging, outstanding, rewarding |

---

## 📋 Adverb Suffixes — Common Patterns

| Suffix | Example Words |
|---|---|
| `-ly` ← most common | successfully, professionally, significantly |
| (flat adverbs — no change) | hard, fast, high, late, early, daily, monthly |

> ⚠️ **Important:** Not all `-ly` words are adverbs!
> `friendly`, `likely`, `costly`, `lively`, `lonely` → **adjectives** ending in `-ly`

---

## 🎯 Common TOEIC Traps

- **Trap 1 — `-ly` ≠ always adverb:** `timely`, `friendly`, `costly`, `quarterly` → **adjectives**
- **Trap 2 — `-al` = adjective OR noun:** `proposal` (noun) vs `professional` (adjective) → check context
- **Trap 3 — `-ant/-ent` = adjective OR noun:** `applicant` (noun/person) vs `significant` (adjective)
- **Trap 4 — Two nouns as options:** e.g., `management` vs `manager` → One is abstract, one is a person → read meaning

---

## 🧠 Exam Thinking Strategy

> **Step 1:** Find the blank in the sentence.
> **Step 2:** Identify the signal word before the blank:
> - `the / a / an / this / their` → **Noun**
> - `is / are / was / were` (as main verb) → **Adjective** (if complement)
> - Before a noun → **Adjective**
> - After a verb or before an adjective → **Adverb**
> **Step 3:** Scan the options — match the suffix to the required class.
> **Step 4:** If two options share the same class → decide by **meaning**.

## 📝 Practice Questions

### Q1
> *"The company's _____ to launch a new product line was met with enthusiasm."*

- (A) decide
- (B) decisive
- (C) decision ✅
- (D) decisively

> 💡 `The company's _____ to...` → after possessive `'s`, before `to-phrase` → **noun** → `decision` (`-tion` = noun suffix).

---

### Q2
> *"All employees must complete the training course _____ by the end of the quarter."*

- (A) success
- (B) successful
- (C) successfully ✅
- (D) succeed

> 💡 Blank modifies verb `complete` → **adverb** → `successfully` (`-ly` = adverb).

---

### Q3
> *"The board approved the _____ to expand operations into Asia."*

- (A) propose
- (B) proposal ✅
- (C) proposed
- (D) proposing

> 💡 `the _____ to expand` → after `the`, before `to` → **noun** → `proposal` (`-al` here = noun).

## 🗂️ Error Log / Memory Tips

| Suffix | Class | Watch out for... |
|---|---|---|
| `-tion/-ment/-ance` | Noun | These are always nouns |
| `-ive/-al/-ous/-able` | Adjective | Don't use before a verb |
| `-ly` | Adverb (usually) | But `friendly`, `timely`, `costly` = adjective! |
| `-ize/-ate/-ify` | Verb | Don't use in noun position |
| `-er/-or/-ist/-ee` | Noun (person) | Never in adjective or adverb slot |

> ✏️ **The 4-Step Suffix System:**
> 1. Find the blank
> 2. Find the signal (article / verb / adjective before blank)
> 3. Match the class (N / V / Adj / Adv)
> 4. Match the suffix → choose answer
