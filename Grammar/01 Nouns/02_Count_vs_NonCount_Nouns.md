# 📌 Count Nouns vs. Non-Count Nouns
**TOEIC Grammar | Unit 01 — Nouns | Part 2 of 6**
*Level: B1–B2 | Focus: Noun Types & Articles/Quantifiers*

---

## 🧭 Overview

> One of the most tested areas in TOEIC Part 5.
> Getting the noun type wrong leads to wrong articles and wrong quantifiers.

---

## 📂 The Two Types

### ✅ Count Nouns
- Can be **singular or plural**
- Can use `a / an / the` or a number
- Examples: `chair`, `report`, `meeting`, `ticket`

> *"I need a chair."* / *"I need three chairs."* ✅

---

### 🚫 Non-Count Nouns
- **No plural form** — never add `-s`
- Cannot use `a / an`
- Examples: `furniture`, `information`, `advice`, `equipment`, `mail`

> *"We need furniture."* ✅
> *"We need a furniture."* ❌
> *"We need furnitures."* ❌

---

## 🔄 Confusing Pairs — Count vs. Non-Count

These pairs have similar meanings but **different grammar rules**. Memorize them!

| Count Noun | Non-Count Noun |
|---|---|
| an account | accounting |
| an advertisement | advertising |
| clothes | clothing |
| a fund | funding |
| furnishings | furniture |
| goods | merchandise |
| a lender | lending |
| a letter | mail |
| a permit | permission |
| a process / procedures | processing |
| a seat | seating |
| a ticket | ticketing |

> 💡 **Pattern:** The `-ing` form often becomes non-count (e.g., `advertise` → `advertising`).

---

## 📏 Articles & Quantifiers: Quick Reference

| Quantifier | Use with | Example |
|---|---|---|
| `many` | Plural count | *many advisors* |
| `several` | Plural count | *several features* |
| `a few` | Plural count | *a few suggestions* |
| `fewer` | Plural count | *fewer options* |
| `much` | Non-count | *much information* |
| `a little` | Non-count | *a little advice* |
| `less` | Non-count | *less funding* |
| `some` | Both | *some problems / some equipment* |
| `more` | Both | *more reports / more data* |
| `most` | Both | *most employees / most furniture* |

---

## ⚠️ The Core Rules

1. **`a / an`** → singular count nouns **only**
2. **`much`** → non-count nouns only → never `much advisors`
3. **`several`** → always plural count → noun must end in `-s`

---

## 🎯 Common TOEIC Traps

- **Trap 1 — `much` with a plural noun:** "Much financial advisors..." → ❌ → Should be **`Many`**
- **Trap 2 — `several` with a singular noun:** "several new *feature*" → ❌ → Should be **`features`**
- **Trap 3 — Using `a` before a non-count noun:** "a furniture", "an information" → Always ❌
- **Trap 4 — Confusing pairs:** `advertisement` (count) vs `advertising` (non-count) → Different grammar!

---

## 🧠 Exam Thinking Strategy

> **Step 1:** Identify the noun in the blank.
> **Step 2:** Decide: Is it **count** or **non-count**?
> **Step 3:** Check which **article or quantifier** works with that type.
> **Step 4:** If two options are both nouns, choose based on count/non-count logic.

## 📝 Practice Questions

### Q1
> *"With so many products to choose from, consumers demand a high _____ of customer service..."*

- (A) advertise
- (B) advertisable
- (C) advertising
- **(D) advertisement ✅**

> 💡 `a high ___` → needs a **singular count noun** → `advertisement` ✅. `advertising` is non-count.

---

### Q2
> *"Many of the policyholders... receive ten percent _____ for cars or houses..."*

- **(A) discount ✅**
- (B) discounting
- (C) discounted
- (D) discounts

> 💡 `ten percent discount` is a fixed collocation. `discounts` without a clear quantifier is less natural here.

---

### Q3
> *"...through an _____ that both young adults and parents could relate to."*

- (A) advertise
- (B) advertisable
- (C) advertising
- **(D) advertisement ✅**

> 💡 `an` before the blank → needs a **singular count noun** → `advertisement` ✅. `advertising` is non-count, so `an advertising` ❌.

## 🗂️ Error Log / Memory Tips

| Mistake | Fix | Memory Trick |
|---|---|---|
| `Much advisors` | `Many advisors` | `much` = unmeasurable; people are always countable |
| `several feature` | `several features` | `several` always = plural → check for `-s` |
| `an information` | `information` (no article) | Information = non-count, like water or air |
| `a furniture` | `furniture` | You can't count furniture — only items IN furniture |
| `advertising` vs `advertisement` | Different grammar | `-ing` = activity (non-count); `-ment` = product (count) |

> ✏️ **Quick Test:** Can you say *"two ___s"*? If yes → count noun. If no → non-count.
