# 📌 Dummy Object "It"
**TOEIC Grammar | Unit 07 — Objects & Complements | Part 2 of 4**
*Level: B1–B2 | Focus: Subject + Verb + it + Adjective + Real Object*

---

## 🧭 Overview

> **Dummy object `it`** is a placeholder that allows a long real object (to-infinitive or that-clause) to be moved to the end of the sentence — placing emphasis on the **adjective** instead.
> This is a fixed, testable structure in TOEIC Part 5.

---

## 📐 The Pattern

```
Subject + Verb + it + Adjective + Real Object
                 ↑                      ↑
           dummy object          to-infinitive phrase
                                 OR that-clause
```

> *"We find **it** easy **to use the software**."*
> → `it` = dummy object · `easy` = adjective · `to use the software` = real object

> *"We find **it** peculiar **that the CEO didn't attend**."*
> → `it` = dummy object · `peculiar` = adjective · `that-clause` = real object

---

## 📋 Verbs That Use This Structure

| Verb | Example |
|------|---------|
| `find` | *find it difficult to...* |
| `make` | *make it possible to...* |
| `consider` | *consider it necessary that...* |
| `think` | *think it important to...* |
| `feel` | *feel it essential that...* |
| `believe` | *believe it wise to...* |

---

## 🔑 The `make it possible` Expression

> `make it + adjective + to-infinitive` is the most tested form.
> After `make it possible/necessary/clear` → always use **to-infinitive** (not bare infinitive).

> ✅ *"The machinery will make it possible **to increase** productivity."*
> ❌ *"...make it possible **increase** productivity."* (missing `to`)

---

## 🎯 Common TOEIC Traps

- **Trap 1 — Bare infinitive after `make it possible`:** `make it possible go` ❌ → `make it possible to go` ✅ — always `to + verb`
- **Trap 2 — Connector choice after adjective:** Blank after adjective in this structure → `that` (for clause) or `to` (for infinitive)
- **Trap 3 — `which/when/about` instead of `that`:** `found it unreasonable that...` ✅ — use `that` to introduce the real object clause, not `which/about/when`

---

## 🧠 Exam Thinking Strategy

> **Step 1:** Spot the structure: `verb + it + adjective + blank`
> **Step 2:** What follows the blank?
> - A full clause (subject + verb) → `that`
> - An action (verb phrase) → `to + verb` (to-infinitive)
> **Step 3:** For `make it possible/necessary` → the answer is almost always `to + base verb`
> **Step 4:** Eliminate bare infinitives, gerunds, and past forms

---

## 📝 Practice Questions

### Q1
> *"The proposed budget increases would make it possible _____ added support to each sector of the firm."*

- **(A) to provide ✅** · (B) provide · (C) provided · (D) providing

> 💡 `make it possible _____` → real object is an action → **to-infinitive** → `to provide`. `provide` = bare infinitive ❌; `providing` = gerund ❌.

### Q2
> *"The whole community found it unreasonable _____ the city proposed building a landfill site..."*

- (A) which · (B) about · **(C) that ✅** · (D) when

> 💡 After `found it unreasonable` → real object is a **full clause** → `that` introduces it. `which` = relative pronoun; `about/when` = wrong connectors for this structure.

### Q3
> *"Supervisors should make it necessary _____ the initiative of each employee."*

- (A) recognize · **(B) to recognize ✅** · (C) of recognizing · (D) recognized

> 💡 `make it necessary _____` → real object is an action → **to-infinitive** → `to recognize`. `recognize` = bare infinitive (no `to`) ❌; `of recognizing` = not a valid structure ❌.

## 🗂️ Error Log / Memory Tips

| Mistake | Fix | Memory Trick |
|---------|-----|--------------|
| `make it possible + bare verb` | `make it possible to + verb` | "possible" → "possible **to** do" (always `to`) |
| `found it + which/when` clause | `that` clause | Dummy object structure uses `that`, not relative pronouns |
| Gerund after `make it adj` | to-infinitive | The real object here is always `to + verb`, not `-ing` |
