# 07_Other_Prepositions

## 📌 Overview
This unit covers **miscellaneous prepositions** that don't fit into time/place/direction/reason categories but appear constantly in TOEIC:
- **Method/means** — by, through, with, without
- **Role/function** — as
- **Comparison** — like, unlike
- **Opposition** — against
- **Limit/scope** — beyond
- **Sequence** — following
- **Addition** — plus

These prepositions also form many **fixed expressions** that are tested directly in Part 5.

---

## 📊 Reference Table — MISCELLANEOUS PREPOSITIONS

| Preposition | Meaning | TOEIC Usage | Example |
|-------------|---------|-------------|---------|
| **by** | method / means / agent | by email, by cash, by law | Access is obtained by providing a valid password. |
| **through** | via / by means of (process) | through collaboration, through the website | Competence is achieved through training. |
| **throughout** | during the entire span | throughout the country | Heavy rains increased water levels throughout the country. |
| **with** | accompaniment / tool | discuss with, equipped with | The children will discuss it with their teacher. |
| **without** | absence of | without disturbing | Listen to music without disturbing anyone. |
| **as** | role / function / capacity | work as, serve as, act as | He served as a section director. |
| **like** | similar to / such as | like jogging, like a professional | Like jogging, walking should have a steady motion. |
| **unlike** | different from / not like | unlike jogging, unlike last year | Unlike jogging, swimming is ideal for any age. |
| **against** | opposition / contradiction | against the law, campaign against | Consumers campaigned against the use of furs. |
| **beyond** | exceeding / past the limit | beyond repair, beyond expectations | Its functions go beyond what is necessary. |
| **following** | after (formal) | following the conference | Following the conference, the banquet will be held. |
| **plus** | in addition to | plus digital music | All the same features plus digital music capabilities. |

## 🧠 Core Rules

### Rule 1 — "as" = role / "like" = similarity
```
AS   = actual role / function (fact)
LIKE = comparison / similarity (analogy)

✅ "He works as a manager." (he IS a manager)
✅ "He works like a manager." (he's NOT a manager, but acts like one)
```

### Rule 2 — "by" vs "through" vs "with"
```
BY      = method / agent in passive voice
THROUGH = process / channel / system
WITH    = tool / instrument / accompaniment

✅ "paid by credit card"     (payment method)
✅ "achieved through effort"  (process)
✅ "cut with scissors"        (tool)
```

### Rule 3 — "like" vs "unlike"
```
LIKE   = same/similar → positive comparison
UNLIKE = different    → negative comparison / contrast

✅ "Like other companies, we offer benefits."  (we're similar)
✅ "Unlike other companies, we offer free gym." (we're different)
```

### Rule 4 — "beyond" = past the limit (often negative or impressive)
```
✅ "beyond repair"        (too damaged → negative)
✅ "beyond expectations"   (exceeded → impressive)
✅ "beyond one's capacity" (too hard → negative)
```

### Rule 5 — "with the exception of" = except for
```
✅ "All employees are satisfied, with the exception of packing staff."
= "All employees are satisfied, except for packing staff."
→ "with the exception of" is the FORMAL version of "except for"
```

## ⚠️ TOEIC Traps

| Trap | Wrong | Correct |
|------|-------|---------|
| "as" vs "like" | works like a teacher (= IS a teacher) | works **as** a teacher |
| "by" vs "through" | achieve by training | achieve **through** training (process) |
| "by" vs "with" | cut by scissors | cut **with** scissors (tool) |
| "beyond" meaning | beyond repair = still fixable | beyond repair = **cannot be fixed** |
| "with the exception of" | with the exception to | with the exception **of** |
| "following" tense | following + future | ✅ "following" often refers to past/sequential events |

## 🎯 Exam Thinking Strategy
1. **"___ proof / evidence / receipt"** → as (role)
2. **Communication method blank?** → by (by email, by phone)
3. **Achievement/success blank?** → through (through training, through collaboration)
4. **Tool/instrument blank?** → with (with a new system)
5. **Opposition/illegal blank?** → against (against the law)
6. **Too much / exceeded blank?** → beyond (beyond repair, beyond expectations)
7. **"With the ___ of"** → exception

## ✏️ Practice Questions

**Q1.** Dayton Electronics recommends that all customers keep their receipts ___ proof of payment.
- (A) **as** ✅
- (B) except
- (C) on
- (D) into

> **Why (A):** "as proof" = in the role/function of proof. The receipt SERVES AS proof — "as" indicates a role or capacity.
> (B) "except" = excluding, doesn't make sense. (C) "on" = about/surface. (D) "into" = direction.

---

**Q2.** Companies can save hundreds on airfares ___ computer linkups which allow international meetings without leaving the office.
- (A) with
- (B) by
- (C) **through** ✅
- (D) following

> **Why (C):** "through computer linkups" = by means of a system/channel. "Through" indicates the process or method used to achieve savings.
> (A) "with" = accompaniment/tool (possible but less precise). (B) "by" = agent/method (possible but "through" is better for systems/channels). (D) "following" = after, doesn't fit.

---

**Q3.** Employees expressed content with their salaries and working hours ___ the exception of those in packing, who requested a pay increase.
- (A) over
- (B) **with** ✅
- (C) following
- (D) of

> **Why (B):** "**with** the exception of" = fixed expression meaning "except for." The full phrase is always "with the exception of."
> (A) "over the exception of" doesn't exist. (C) "following the exception of" doesn't exist. (D) "of the exception of" doesn't exist.
