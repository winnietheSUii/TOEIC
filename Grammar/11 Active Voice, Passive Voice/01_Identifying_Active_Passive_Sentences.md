# 📌 Identifying Active / Passive Sentences
**TOEIC Grammar | Unit 11 — Active & Passive Voice | Part 1 of 4**
*Level: B1–B2 | Focus: Object Present = Active · Object Absent = Passive*

---

## 🧭 Overview

> The single most reliable rule for choosing between active and passive voice:
> **If a transitive verb has an object after it → Active Voice.**
> **If a transitive verb has NO object after it → Passive Voice.**
> This rule applies to main verbs, to-infinitives, and verbs inside relative clauses.

---

## 📐 Core Decision Rule

```
Transitive verb + OBJECT present  →  Active Voice   (V)
Transitive verb + NO OBJECT       →  Passive Voice  (be + past participle)
```

---

## 📋 All Four Contexts

### 1️⃣ Main Clause Verb

| Has Object? | Voice | Example |
|-------------|-------|---------|
| ✅ Yes | Active | *"The assistant **uses** the computer."* — `the computer` = object |
| ❌ No | Passive | *"A new machine **will be installed**."* — no object follows |

---

### 2️⃣ To-Infinitive Phrase

| Has Object? | Voice | Example |
|-------------|-------|---------|
| ✅ Yes | Active | *"The tenant is supposed **to pay** the rent."* — `the rent` = object |
| ❌ No | Passive | *"The draft was supposed **to be discussed**."* — no object |

---

### 3️⃣ Relative Clause Verb

| Has Object? | Voice | Example |
|-------------|-------|---------|
| ✅ Yes | Active | *"...an author who **writes** children's fairy tales..."* — `children's fairy tales` = object |
| ❌ No | Passive | *"...items that **are listed** in the files."* — no object |

---

## 🔑 The One-Question Test

> After placing the verb in the blank — ask: **"Is there a noun (object) immediately after this verb?"**
> - YES → Active (`write`, `expedite`, `attach`)
> - NO → Passive (`written`, `to be expedited`, `attached`)

---

## 🎯 Common TOEIC Traps

- **Trap 1 — Missing object = passive, but a prepositional phrase follows:** `"written in the blanks"` — `in the blanks` is a prep phrase, not an object → passive ✅
- **Trap 2 — To-infinitive with object:** Look inside the infinitive phrase for an object, not just at the main verb
- **Trap 3 — Gerund `-ing` disguised as passive:** `writing` ≠ passive. Passive = `be + past participle` only
- **Trap 4 — Past participle vs. past simple:** `written` (past participle) ≠ `wrote` (past simple). Only past participle can form passive.

---

## 🧠 Exam Thinking Strategy

> **Step 1:** Is the verb transitive (can it take a direct object at all)? → Only transitive verbs can be passive.
> **Step 2:** Find what comes directly after the verb in the sentence. Is it a noun/pronoun (object)?
> - YES → Active
> - NO (prep phrase / nothing / clause) → Passive → use `be + past participle`
> **Step 3:** For to-infinitive: check inside the phrase, not in the main clause.
> **Step 4:** For relative clauses: check what follows the relative pronoun + verb.

## 📝 Practice Questions

### Q1
> *"The e-mail addresses and telephone numbers should be carefully _____ in the blanks provided."*

- **(A) written ✅** · (B) write · (C) wrote · (D) writing

> **Why (A) is correct:** The sentence has no object after the blank — `in the blanks` is a prepositional phrase, not a direct object. No object = **passive voice** = `be + past participle`. The auxiliary `be` is already provided (`should be`), so the correct form is the **past participle `written`**.
>
> **Why (B) is wrong:** `write` is a bare infinitive / base form. It cannot follow `should be` as a passive construction.
>
> **Why (C) is wrong:** `wrote` is the **simple past tense** of `write`. Past simple ≠ past participle. You cannot say `should be wrote`.
>
> **Why (D) is wrong:** `writing` is a gerund/present participle. `should be writing` would be a progressive, meaning an ongoing action — grammatically possible but changes meaning entirely, and there's no object here anyway. 

---

### Q2
> *"_____ the mailing of the package, you will need to add five dollars more to the shipping fee."*

- **(A) To expedite ✅** · (B) To be expediting · (C) To be expedited · (D) Will expedite

> **Why (A) is correct:** The to-infinitive phrase has a clear object: `the mailing of the package`. Object present = **active voice** = `to + base verb` = `to expedite`. The subject of the action is logically `you` (the person doing the expediting).
>
> **Why (B) is wrong:** `To be expediting` is a progressive passive — grammatically awkward and not standard. Even if progressive, the active `to be expediting the mailing` would need a subject doing the expediting, which doesn't fit.
>
> **Why (C) is wrong:** `To be expedited` is the **passive infinitive**. Passive means the subject receives the action — but here `you` are the one doing the expediting, not receiving it. Passive form would mean "the mailing expedites you," which makes no sense.
>
> **Why (D) is wrong:** `Will expedite` is a conjugated future verb. It cannot start an introductory to-infinitive phrase; it would create a sentence without a proper subject structure.

---

### Q3
> *"You must fill out the tax form, a copy of which is to _____ the contractual agreement you received on the first day."*

- **(A) attach ✅** · (B) attachment · (C) attaching · (D) attached

> **Why (A) is correct:** The to-infinitive `to _____` has an object: `the contractual agreement`. Object present = **active voice**. The structure is `is to + bare infinitive` (expressing obligation/arrangement) → `to attach`. You (the subject) attach the agreement to the copy.
>
> **Why (B) is wrong:** `attachment` is a **noun**. A noun cannot follow `to` in a to-infinitive slot. `is to attachment` is grammatically impossible.
>
> **Why (C) is wrong:** `attaching` is a gerund/present participle. `is to attaching` mixes structures incorrectly. The pattern `is to + V-ing` doesn't exist in standard grammar.
>
> **Why (D) is wrong:** `attached` is a past participle. `is to attached` would imply `is to be attached` (passive infinitive), which would mean the copy is the thing being attached — but the sentence says there IS an object (`the contractual agreement`), so active voice is correct.

## 🗂️ Error Log / Memory Tips

| Context | Check For | Voice |
|---------|-----------|-------|
| Main verb | Noun/pronoun directly after verb | Active if yes, Passive if no |
| To-infinitive | Object inside the infinitive phrase | Active if yes (`to do it`), Passive if no (`to be done`) |
| Relative clause | Object after the relative verb | Active if yes (`that writes books`), Passive if no (`that are written`) |
| Prepositional phrase | `in/on/at + noun` ≠ object | Still passive — prep phrase ≠ direct object |
