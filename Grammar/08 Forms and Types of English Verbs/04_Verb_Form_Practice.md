## 🔑 Master Reference — Verb Form After Each Trigger

| Trigger | Required Form | Example |
|---------|--------------|---------|
| **Modal** (`will/can/must/should/may`) | Bare infinitive | *will **succeed*** |
| **`do/does/did`** (negative/question/inversion) | Bare infinitive | *did not **arrive*** |
| **`had better`** | Bare infinitive | *had better **turn** in* |
| **`has/have/had`** (perfect tense) | Past participle | *has **applied*** |
| **`is/are/was/were`** (progressive) | Present participle (`-ing`) | *is **compiling*** |
| **`is/are/was/were`** (passive) | Past participle | *was **delivered*** |
| **Demand/suggest/require + `that`** | Bare infinitive | *requests that she **submit*** |
| **Essential/imperative/important + `that`** | Bare infinitive | *imperative that he **contact*** |
| **`to`** (to-infinitive) | Base form (with `to`) | *able **to attend*** |
| **Transitive verb** | Direct object (no preposition) | *discuss **the issue*** |
| **Intransitive verb** | Preposition + object | *talk **about** the issue* |

## ⚠️ Common Error Patterns — All in One Place

### ❌ Wrong → ✅ Right

| Error Sentence | Problem | Fixed |
|----------------|---------|-------|
| *Crystal will gladly **acceptance** her boss' offer.* | Noun after modal | *...will **accept**...* |
| *It is important that the city **receives** state funds.* | 3rd `-s` in that-clause | *...the city **receive**...* |
| *Should you **are** unable to attend...* | Inflected verb in inversion | *Should you **be** unable...* |
| *You had better **turned** in those evaluations.* | Past tense after `had better` | *...had better **turn**...* |
| *A ceremony will **held** in honor of...* | Missing `be` in passive | *...will **be held**...* |
| *Only on Saturday does the clinic **accepts** patients.* | 3rd `-s` after `does` | *...does the clinic **accept**...* |
| *She is **compile** the documents.* | Wrong progressive form | *She is **compiling**...* |
| *It is essential that we **to remain** aware.* | `to-infinitive` in that-clause | *...we **remain** aware.* |
| *Kate has **apply** for vacation time.* | Wrong past participle | *Kate has **applied**...* |
| *It is imperative that you **will submit** all reports.* | `will` inside that-clause | *...that you **submit**...* |
| *The commentator failed to **notify to** us.* | Transitive verb + wrong preposition | *...failed to **mention to** us.* |
| *We have to **discuss about** export sales.* | Transitive + preposition | *...**discuss** export sales / **talk about** export sales.* |

## 📋 The 5 Verb Form Slots — Quick Identification

```
1. Modal / did / had better + __________ = BARE INFINITIVE
2. has / have / had + __________ = PAST PARTICIPLE  
3. is / are / was / were + __________ + -ing = PRESENT PARTICIPLE
4. is / are / was / were + __________ (passive) = PAST PARTICIPLE
5. suggest/require/essential + that + __________ = BARE INFINITIVE
```

## 🎯 Error Diagnosis — Which Trap Did You Fall Into?

| You chose... | Trap name | Likely cause |
|-------------|-----------|-------------|
| Verb + `-s` after modal/does | **3rd person trap** | Forgot modal/aux removes -s |
| Past tense after `did` | **Double past trap** | `did` already marks past |
| `to + verb` after modal | **to-infinitive trap** | Modal ≠ requires `to` |
| Present tense in that-clause | **Tense retention trap** | Forgot mandative = bare infinitive |
| `are`/`is` for passive in that-clause | **Inflection trap** | Passive after trigger = bare `be` |
| Noun after modal | **Word class trap** | Modal + verb only (never noun) |
| `discuss about` | **Transitive preposition trap** | Transitive verbs need no preposition |

## 📝 Mixed Practice Questions

### Q1
> *"Crystal will gladly _____ her boss' offer of a promotion and a raise."*

- **(A) accept ✅** · (B) acceptance · (C) accepts · (D) accepting

> 💡 `will` = modal → bare infinitive → `accept`.

### Q2
> *"It is important that the city _____ state funds for its budget."*

- (A) receives · **(B) receive ✅** · (C) receiving · (D) received

> 💡 `important that` = trigger adjective → bare infinitive → `receive` (no `-s`).

### Q3
> *"You had better _____ in those evaluations before you put in a request for time off."*

- **(A) turn ✅** · (B) turned · (C) turning · (D) have turned

> 💡 `had better` → bare infinitive → `turn`. `turned` = past ❌; `turning` = gerund ❌; `have turned` = perfect ❌.

## 🗂️ Error Log / Memory Tips

| Rule | Quick Reminder |
|------|---------------|
| Modal → bare | Will/can/must/should → base verb, no extras |
| `did` → bare | Past already in `did` — verb stays base |
| `had better` → bare | Warning structure → base verb always |
| `has/have` → past participle | Perfect tense = `-ed` or irregular past participle |
| `is/are` + `-ing` | Progressive = present participle |
| `is/are` + past participle | Passive = past participle (not `-ing`) |
| That-clause trigger → bare | Demand/suggestion/necessity = base verb, no inflection |
| That-clause passive → `be + p.p.` | `be` stays bare (not `is/are`) |
