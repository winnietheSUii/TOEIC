## TRICK 1: Position Framework — What Does the Blank Need?

### Look BEFORE the blank

| What's Before | → Blank Must Be |
|--------------|----------------|
| `a / an / the ___` | **NOUN** |
| `adj ___` (e.g., "significant ___") | **NOUN** |
| `___ of / ___ for / ___ in` (prep follows) | **NOUN** |
| `be ___` (nothing after) | **ADJ** or **NOUN** |
| `be ___ by` | **PAST PARTICIPLE** (passive) |
| `very / quite / rather / too ___` | **ADJ** or **ADV** |
| `subject + ___` (main verb position) | **VERB** (correct form) |
| `have / has / had ___` | **PAST PARTICIPLE** |
| `be + ___` + verb ending in -ing | **ADV** or **ADJ** |

### Look AFTER the blank

| What's After | → Blank Must Be |
|-------------|----------------|
| `___ + noun` (noun follows, no verb) | **ADJ** or **PREP** or **DET** |
| `___ + S + V` (full clause follows) | **CONJUNCTION** |
| `___ + noun phrase` (no verb) | **PREPOSITION** |
| `verb + ___` (blank after verb, at end) | **ADV** (modifying verb) |
| `___ + adj/adv` (blank before adj) | **ADV** (degree: very/quite) |
| `___ + to + verb` | **ADJ** (e.g., "able to", "likely to") |

### Quick Decision Tree
```
Blank after article (a/the/an)?       → NOUN
Blank after be-verb, before nothing?  → ADJ
Blank modifies verb/adj/adv?          → ADV
Blank before full clause (S+V)?       → CONJUNCTION
Blank before noun only (no verb)?     → PREPOSITION
```

## TRICK 2: Word Form — Check the Ending

| Ending | Usually | Example |
|--------|---------|---------|
| `-tion / -sion / -ment / -ness / -ty / -ance / -ence / -ity` | NOUN | information, management |
| `-ive / -al / -ous / -ful / -less / -able / -ible / -ic / -ary` | ADJ | effective, financial |
| `-ly` (on ADJ) | ADV | quickly, effectively |
| `-ly` (on NOUN) | ADJ | friendly, likely, costly |
| `-ize / -ify / -en / -ate` | VERB | organize, clarify |
| `-ed` | ADJ or PAST TENSE/PARTICIPLE | dedicated, announced |
| `-ing` | ADJ (active) or GERUND | interesting, managing |

> ⚠️ **-ly trap:** friendly / lovely / lively / costly / likely / timely = ADJECTIVE not ADVERB

## TRICK 3: Confusing Adverbs (Part 5 Common Traps)

### Time Adverbs
| Word | Meaning | Position | Used With |
|------|---------|----------|----------|
| **yet** | up to now / still (neg) OR "but" (conj) | end of sentence | negative / question |
| **still** | continuing | MIDDLE (before verb, after be) | any tense |
| **already** | earlier than expected | MIDDLE | present perfect |
| **soon** | in a short time | end / front | future |
| **lately / recently** | in recent time | end or front | present perfect |
| **currently** | at this moment | front or middle | present continuous |
| **previously / formerly** | before now | front | past |
| **immediately** | right away | front or end | any |
| **eventually** | finally after a long time | front | any |

### Degree Adverbs
| Word | Meaning | Modifies |
|------|---------|---------|
| **very / extremely / highly** | strong degree | adj / adv |
| **quite / rather / fairly** | moderate degree | adj / adv |
| **nearly / almost** | close to 100% | adj / verb / number |
| **barely / hardly / scarcely** | almost NOT (negative meaning) | verb |
| **even** | surprising, to emphasize | verb / adj / more |
| **only / merely / just** | nothing more than | verb / adj / noun |

> ⚠️ **hardly/barely/scarcely = negative** → don't add "not"
> ❌ "can't barely" = wrong | ✅ "can barely" = correct

## TRICK 4: Conjunction vs Preposition — THE Most Common TOEIC Trap

### THE RULE:
```
CONJUNCTION  →  followed by  S + V  (full clause)
PREPOSITION  →  followed by  NOUN / NOUN PHRASE  (no verb)
```

### Master Table: Same Meaning, Different Form

| Meaning | CONJUNCTION (+S+V) | PREPOSITION (+noun) |
|---------|-------------------|---------------------|
| **Reason** | because, since, as | because of, due to, **owing to**, on account of, as a result of |
| **Concession** | although, even though, though, while, whereas | despite, in spite of, **notwithstanding** |
| **Time** | when, while, before, after, until, once, as soon as | before, after, until, during, **upon**, following, **prior to** |
| **Condition** | if, unless, provided that, as long as | without, in case of |
| **Purpose** | so that, in order that | for, for the purpose of |

### Quick Test:
```
"___ the rain, we canceled."    → before noun "the rain" → PREPOSITION → "Due to"
"___ it rained, we canceled."  → before clause → CONJUNCTION → "Because"
```

## TRICK 5: Conjunctive Adverbs vs Conjunctions

> Conjunctive adverbs = **connecting adverbs** that join two SEPARATE sentences

| Meaning | CONJUNCTION (joins clauses) | CONJUNCTIVE ADV (joins sentences) |
|---------|----------------------------|----------------------------------|
| **Contrast** | but, yet | **however**, nevertheless, nonetheless |
| **Result** | so | **therefore, thus, hence, consequently, accordingly** |
| **Addition** | and | **moreover, furthermore, in addition, besides** |
| **Alternative** | or | **otherwise, instead** |
| **Time seq.** | then | **subsequently, meanwhile** |

### Usage Pattern:
```
CONJUNCTION:       S + V, but S + V.
CONJUNCTIVE ADV:   S + V; however, S + V.
                   S + V. However, S + V.
```
> ⚠️ TOEIC trap: "however" ≠ "but" structurally — cannot use before S+V directly without semicolon/period

## TRICK 6: Key Preposition Meanings (TOEIC High-Frequency)

### Cause / Reason
| Prep | Meaning | Example |
|------|---------|---------|
| **due to** | because of | Due to the delay, we... |
| **owing to** | because of (formal) | Owing to circumstances... |
| **because of** | reason | Because of the rain... |
| **on account of** | as a result of | On account of... |
| **in light of** | considering | In light of the results... |
| **given** | considering | Given the situation... |

### Concession
| Prep | Meaning | Example |
|------|---------|---------|
| **despite** | although | Despite the challenges... |
| **in spite of** | although | In spite of delays... |
| **notwithstanding** | despite (very formal) | Notwithstanding concerns... |
| **regardless of** | no matter what | Regardless of cost... |

### Time
| Prep | Meaning | Example |
|------|---------|---------|
| **prior to** | before | Prior to the meeting... |
| **following** | after | Following the announcement... |
| **upon** | immediately after | Upon arrival... |
| **throughout** | during the whole period | Throughout the year... |
| **amid / amidst** | in the middle of / during | Amid the crisis... |
| **pending** | while waiting for | Pending approval... |
| **within** | before the end of | Within two weeks... |

### Addition / Inclusion
| Prep | Meaning | Example |
|------|---------|---------|
| **in addition to** | also, plus | In addition to salary... |
| **along with** | together with | Along with the report... |
| **as well as** | and also | Experience as well as skills... |
| **including** | with (named) | 10 items, including... |
| **except (for)** | not including | All items except one... |
| **aside from / apart from** | except / in addition to | Aside from cost... |
| **instead of** | in place of | Instead of cash... |
| **in place of** | instead of | In place of the meeting... |

### Purpose / About
| Prep | Meaning | Example |
|------|---------|---------|
| **regarding / concerning** | about | Regarding your request... |
| **as for / as to** | concerning | As for the budget... |
| **for the purpose of** | in order to | For the purpose of... |
| **on behalf of** | representing | On behalf of the team... |

### Other Important Ones
| Prep | Meaning | Example |
|------|---------|---------|
| **beyond** | more than / past | Beyond expectations... |
| **against** | in opposition to | Against regulations... |
| **throughout** | all through | Throughout the company... |
| **toward(s)** | in direction of | Toward the goal... |
| **across** | throughout / on other side | Across the department... |
| **through** | by means of / during | Through collaboration... |

## TRICK 7: Subject-Verb Agreement Quick Checks

```
[The number of + plural noun] + singular verb
[A number of + plural noun]  + plural verb

[Either A or B]   → verb agrees with B (closer)
[Neither A nor B] → verb agrees with B (closer)
[Not only A but also B] → verb agrees with B

[each / every / either / neither / anyone / no one] → singular verb
[both / many / several / few]                       → plural verb
[none / some / all / most / half] + of + noun       → agrees with noun
```

## TRICK 8: Fast Part 6 Strategy

```
Step 1: Skim passage (30 sec) → get: topic, tone, tense
Step 2: For each blank:
   - Grammar blank  → apply Position Framework (Trick 1)
   - Context blank  → read surrounding 1-2 sentences, pick word that fits meaning
   - Sentence insertion → check: pronoun reference, topic flow, connector logic
Step 3: Tense check → all blanks should match passage tense (unless meaning requires otherwise)
```

### Sentence Insertion Checklist:
- Does "this / these / it / they" in the inserted sentence refer to something mentioned before?
- Does the sentence AFTER the blank logically follow the inserted sentence?
- Does the connector word (however / therefore / in addition) match the relationship?
