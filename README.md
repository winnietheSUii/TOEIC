## 🧠 Exam Strategy (Quick Reference)

**Part 5 — Incomplete Sentences (40 Qs)**
1. Read the blank's position signal (`a/the` → noun · before noun → adj · modifies verb → adv)
2. Scan suffixes of 4 options → classify N / V / Adj / Adv instantly
3. Eliminate wrong classes → if 2 remain, decide by meaning
4. Target time: **≤ 20 seconds per question**

**Part 6 — Text Completion (16 Qs)**
- Read the full paragraph before answering
- Connecting adverbs and tense consistency are key here

**Part 7 — Reading Comprehension (54 Qs)**
- Grammar knowledge = faster reading = more time for double passages
- Relative clauses and noun clauses help you parse long sentences
